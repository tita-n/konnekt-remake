# Vendored fonts

These are the Latin variable subsets used by the app. They are self-hosted so a
production build never depends on the Google Fonts API being reachable.

| File | Family | Upstream |
| --- | --- | --- |
| `inter-latin-variable.woff2` | Inter (100–900) | https://fonts.google.com/specimen/Inter |
| `plus-jakarta-sans-latin-variable.woff2` | Plus Jakarta Sans (200–800) | https://fonts.google.com/specimen/Plus+Jakarta+Sans |

Both families are licensed under the SIL Open Font License 1.1; the license text
is in `OFL.txt`.
